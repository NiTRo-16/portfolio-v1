# Parth Gautam: Portfolio

Personal portfolio of **Parth Gautam**, B.Tech Computer Science student at IPS Academy, Indore, and aspiring AI/ML engineer.

A single-page, animated website built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Features

- Dark, glass-style design with a drifting tile wall hero and live IST clock
- Live project previews:
  - **AI Weed Detection Robot**: simulated ESP32-CAM feed detecting crops and targeting weeds
  - **Artemis**: interactive phishing URL risk analyzer (paste any link)
  - **Algorithmic Trading Bot**: live candlestick chart with SMA crossover signals
- Stacking project cards, scroll-lit About text, count-up stats and a skills marquee
- Responsive down to phone width, and respects reduced-motion settings

## Run locally

Open `index.html` in any browser.

## Deploy

- **GitHub Pages:** Settings → Pages → Source: `main` branch, `/ (root)`.
- **GoDaddy:** upload `index.html` to the `public_html` folder.
